# Home Theater Project
- status: Planning
- created: 2024-05-21
- purpose: Optimized for viewing action movies with practical effects (e.g., Heat, Mad Max).

## Requirements
- **Audio Priority**: Visuals are secondary to sound for action movies.
- Audio: Needs to handle dynamic range (e.g., "Heat" downtown shootout).
- Video: High contrast and motion handling for action sequences.

## Implementation Plan
- **Phase 1**: Good sound system.
- **Phase 2**: Projector (later date).
