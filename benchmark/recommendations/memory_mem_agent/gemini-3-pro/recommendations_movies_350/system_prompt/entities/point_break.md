# Point Break (1991)
- **Genre**: Action
- **Cast**: [[entities/keanu_reeves.md]], Patrick Swayze
- **Stunts**:
    - **Skydiving Scene**: Famous for the practical skydiving sequences where the actors (Swayze) actually jumped.
    - **No Parachute Jump**: Keanu Reeves' character jumps without a chute to catch Bodhi. The close-ups were practical rig work, not CGI.
- **User Opinion**: Appreciates the practical nature of the stunts, specifically the jump without a parachute, contrasting it with modern CGI usage.
