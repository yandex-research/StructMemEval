# The Crew
- **Genre**: Cooperative card game / Trick-taking
- **User Opinion**: Found it to be a refreshing cooperative experience.
- **Mechanics**: Praised the hidden information aspect ("no one could see all the cards"), noting it forces every player to contribute and prevents alpha gaming.
- **Gameplay Dynamic**: Appreciated that the game necessitated discussions about probabilities and timing, contrasting this favorably with other cooperative games where one person calculates optimal moves for everyone.
