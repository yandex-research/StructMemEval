# Spirit Island
- type: Board Game
- genre: Cooperative, Strategy
- user_opinion: Positive. Describes it as "that perfect cooperative experience," marking a significant exception to previous dislikes of the genre. Finds shared victory "amazing when it works."
- mechanics_liked: Unique player powers and separate boards prevent "quarterbacking" by ensuring no single player can mentally track or control the entire game state. Players are forced to "discuss strategy rather than one person dictating moves." 
- partner_dynamic: The complete difference in spirit abilities required coordination strategies, preventing one person from optimizing everything for the group.
- balance_observation: The adversary system creates "tension without desperation" when calibrated properly, distinguishing it from games that feel hopeless or trivial.
