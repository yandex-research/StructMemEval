# Scythe
- **Experience**: Disappointing experience despite high production value.
- **Visuals**: Beautiful components acknowledged.
- **Combat System**: Criticized for creating "kingmaking" problems.
- **Player Interaction**: Results in passive players during others' turns.
- **Agency**: Feels there is no meaningful agency when not the active player.
- **Encounter System**: Criticized as "random punishment rather than meaningful choice," lacking strategic depth.
