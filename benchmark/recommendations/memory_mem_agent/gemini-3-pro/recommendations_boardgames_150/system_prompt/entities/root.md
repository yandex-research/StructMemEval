# Root
- **Asymmetry**: Creates genuine tension because players cannot optimize engines in isolation; they must react to opponents different mechanical engines.
- **Genre**: Asymmetric Strategy Board Game
- **Longevity**: Remains surprising and engaging after ten plays, showing deep replay value.
- **Why It Works**: Variable setup and asymmetric factions ensure each game feels fresh rather than repetitive.
- **Faction Design**: Different factions play like entirely different games.
- **Faction Experience**: Playing Vagabond feels completely different from Marquise de Cat.
