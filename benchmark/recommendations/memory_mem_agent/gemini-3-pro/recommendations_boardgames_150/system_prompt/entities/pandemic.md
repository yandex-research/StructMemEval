# Pandemic
- type: Board Game
- user_opinion: Dislikes it. Felt like a spreadsheet exercise rather than a game. Disliked the dynamic where one player calculated optimal moves while others just executed instructions with zero meaningful decisions (alpha gaming/quarterbacking issue).
- specific_frustration: Recalls playing as the Medic and spending three turns just moving where told by another player, reinforcing the lack of agency.
- thematic_disconnect: The disease cubes stopped feeling like threats and just became tokens to moved around.
- comparison: Forbidden Island is considered even worse for the quarterbacking issue. [[entities/forbidden_island.md]]
