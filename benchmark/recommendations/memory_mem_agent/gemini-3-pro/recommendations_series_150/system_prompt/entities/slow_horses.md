# Slow Horses
- genre: Spy thriller
- opinion: Proves you don't need glamour to create tension.
- appreciation: Values flawed people making hard choices in unglamorous settings.
- tension_source: Character choices and setting reality rather than action spectacle.

## Characters
- **Jackson Lamb**: Described as the "anti-Bond"—overweight, rude, but brilliant. A character you "can't look away" from.
