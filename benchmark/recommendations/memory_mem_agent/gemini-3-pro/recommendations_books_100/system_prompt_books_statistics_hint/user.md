## Reading Patterns
- appreciates_realistic_conflict: true (prefers problems that come from real life rather than forced miscommunications)
- values_extensive_world_building: true (loves fully realized worlds with own rules and history)
- appreciates_developed_side_characters: true (values side characters that feel like they have lives outside the main plot)
- prefers_hard_magic_systems: true (values costs/consequences because it makes choices matter, avoids deus ex machina)
- needs_character_growth: true (prioritizes character arcs over plot events; feels cheated if characters remain the same by the end)
- hesitant_about_long_series: true (expressed intimidation at starting a massive 10-book series like Malazan)
- requires_finished_series: true (burned by huge sagas without ends, prefers multiple completed shorter series over massive unfinished ones like decalogies)

- values_structured_plotting: true (trusts authors like Sanderson who outline from the start)
- dislikes_unplanned_subplots: true (frustrated when new subplots pop up with no connection to earlier threads; dislikes feeling like authors make things up as they go)
- requires_happy_ending: false (happy endings not required, but resolution must feel planned)
- dislikes_wandering_plots: true (wandering plots break trust; needs to feel author knew the destination)
- appreciates_long_term_foreshadowing: true (loves when seeds planted in early books bloom much later)

- dislikes_miscommunication_trope: true (hates when characters refuse to communicate to artificially extend drama)
- tolerates_tropes_if_authentic: true (fake dating, enemies-to-lovers acceptable if characters feel real)
- dislikes_artificial_drama: true (drops books if characters act dumb just to extend drama)
- loves_romance_genre: true
- needs_space_between_romances: true (loves the romance genre, but must pace reads to avoid them blurring together)
- alternates_genres: true (specifically sandwiches romances between fantasy and horror to keep things fresh)
- prefers_psychological_horror: true (prefers dread over gore, believes silence is louder than screams in horror)

- prefers_accessible_historical_prose: true (loves historical settings but disengages if prose is too academic or details overwhelm story)
- prefers_audio_poetry: true (print poetry makes them anxious and feels like a test, but audio/spoken poetry makes them curious and flows like music)
