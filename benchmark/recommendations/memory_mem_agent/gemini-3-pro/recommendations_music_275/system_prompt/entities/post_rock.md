# Post-Rock
- genre_characteristics: Uses rock instrumentation for texture and timbre rather than riffs; focuses on dynamics (quiet to loud crescendos) and atmosphere.
- key_elements: heavily effects-laden guitars, lengthy instrumental passages, cinematic scope.
- relevant_artists: [[entities/godspeed_you_black_emperor.md]], [[entities/explosions_in_the_sky.md]], [[entities/mogwai.md]]
- vocal_style: Often instrumental or uses vocals as an instrument (non-lyrical).
