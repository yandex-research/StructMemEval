# Porcupine Tree
- genre: Progressive Rock / Alternative Metal
- leader: [[entities/steven_wilson.md]]
- musical_style: Melancholic, atmospheric, heavy but melodic, complex time signatures.
- key_albums: In Absentia, Fear of a Blank Planet, Deadwing
- relevance_to_user: Bridges the gap between [[entities/pink_floyd.md]] (atmosphere) and [[entities/tool.md]] (rhythmic complexity/heaviness).
- production_quality: Audiophile standard (leader Steven Wilson is a renowned remixer of classic albums like King Crimson and Yes).
