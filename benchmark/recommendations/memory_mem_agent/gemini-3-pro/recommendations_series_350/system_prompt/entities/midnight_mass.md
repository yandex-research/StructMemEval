# Midnight Mass
- genre: Horror / Drama
- themes: Faith, community, character psychology, escalating dread
- style: Restraint over excess, psychological horror, no cheap jump scares
- narrative_focus: The vampire mythology is secondary; the true focus is how belief transforms (or corrupts) a community, using supernatural elements solely to serve the human drama.
- standout_performance: Hamish Linklater as Father Paul. His conviction in delivering monologues elevates material that could otherwise feel pretentious, making the audience "lean in" rather than roll their eyes.
- finale_insight: The "death is beautiful" sermon (Erin's monologue) works specifically because it is earned through character development, differentiating it from empty philosophical posturing.
