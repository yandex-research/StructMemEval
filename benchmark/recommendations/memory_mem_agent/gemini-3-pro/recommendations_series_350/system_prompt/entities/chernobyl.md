# Chernobyl
- genre: Historical Drama / Miniseries
- user_opinion: Masterful historical drama where every frame radiates dread without melodrama. Appreciates that it trusts the audience to feel the horror without showing graphic radiation burns constantly.
- user_comparison: Used as a benchmark for how implied horror resonates deeper than gore, contrasting it with The Last of Us which occasionally forgets this lesson. [[entities/the_last_of_us.md]]
