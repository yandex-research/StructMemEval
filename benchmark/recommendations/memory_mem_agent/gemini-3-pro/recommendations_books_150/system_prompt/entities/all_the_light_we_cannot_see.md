- genre: Historical Fiction
- status: Read

## Review
- **Reason for Enjoyment**: "Weaves history and character so seamlessly that you forget you're learning—you're just living with them."
- **Contrast**: This directly addresses the user's main critique of the genre (dense, detached history) by integrating historical context into lived character experience.
- **Characters**: Specifically felt that Marie-Laure and Werner were "real people, not historical puppets," reinforcing the immersive quality of the historical setting.
