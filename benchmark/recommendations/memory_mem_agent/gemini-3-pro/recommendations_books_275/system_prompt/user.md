## Fantasy Selection Strategy
- **Tier 1 (Safe)**: Standalone Epics like [[entities/warbreaker.md]] or [[entities/priory_of_the_orange_tree.md]] (massive scope, one volume).
- **Tier 2 (Moderate)**: Completed Trilogies like [[entities/mistborn.md]] or [[entities/licanius_trilogy.md]] (known ending, confined risk).
- **Tier 3 (High Reward)**: Long finished series broken into arcs (e.g., Realm of the Elderlings).
- **Avoid**: Unfinished series (Kingkiller, ASOIAF) unless author trust is absolute (Sanderson).
