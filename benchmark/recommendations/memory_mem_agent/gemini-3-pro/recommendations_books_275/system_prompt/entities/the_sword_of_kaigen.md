# The Sword of Kaigen
- author: M.L. Wang
- genre: Fantasy (Standalone)
- key_elements:
    - Elemental magic treated as martial arts/physics (Hard Magic)
    - Intense character study of a mother/warrior (Misaki)
    - Emotional devastation and rebuilding
- recommendation_reason: Matches user's love for logical magic systems (Sanderson-esque) but with the emotional depth/character focus of *The Nightingale*.
