# Brandon Sanderson
- **Role**: Fantasy Author
- **Trust Factor**: User trusts him with time investment because he consistently delivers and ties up loose ends. [[user.md]]

## Writing Style Preferences
- **Magic Systems**: User appreciates his logical and consistent magic systems where the impossible feels possible. Values the costs and boundaries he implements.
- **Characterization**: Praised for creating distinct character voices in large ensemble casts (e.g., *Stormlight Archive*). [[entities/stormlight_archive.md]]
- **World-Building Technique**: Praised for "magical ecology" where world details (like spren) explain the setting naturally, avoiding dense info-dumps.
- **Story Structure**: User values his ability to write standalones (e.g., *Elantris*) with complete, satisfying arcs in a single volume, avoiding necessary sequels. [[entities/elantris.md]]
