# User Information

## Core Reading Identity
1. **The "Neighbor" Test (Grounded Authenticity)**: Characters must feel real first—defined by jobs, relationships, and logical choices—before the genre elements (magic, horror, history) interact with them. You reject "manufactured drama" (miscommunication, stupidity) and value "circumstance-driven conflict."
2. **The "Contract" Requirement (Trust & Resolution)**: You view reading as an investment requiring a guaranteed return. You favor completed series, "architect" authors (Sanderson), and distinct payoffs. You avoid "meandering" plots, unfinished series, and ambiguity that feels like the author lost control.
3. **The "Intuition" Barrier (Accessibility over Density)**: You reject high-friction reading. If the prose is too dense (Wolf Hall), the historical mindset too alien (Ancient Rome), or the format too abstract (Print Poetry), you disengage. You prefer "intuitive stakes" where the emotional logic requires no translation.
