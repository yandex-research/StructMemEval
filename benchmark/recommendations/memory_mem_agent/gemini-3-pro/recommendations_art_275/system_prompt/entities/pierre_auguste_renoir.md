# Pierre-Auguste Renoir
- style: Impressionism
- medium: Painting
- **Exhibitions**: Featured in an exhibit at the National Gallery. [[entities/national_gallery.md]]

## Criticisms
- **Over-Polish**: User finds his work (specifically the Boating Party) too "saccharine" and polished, lacking the "friction" of real life and human interaction. [[entities/luncheon_of_the_boating_party.md]]
- **Nature's Postcard**: User describes Renoir's style as 'nature's postcard' and 'pretty decoration,' contrasting it unfavorably with Monet's 'nature's truth.'
