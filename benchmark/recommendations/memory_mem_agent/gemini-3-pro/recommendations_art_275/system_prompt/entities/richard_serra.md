# Richard Serra
- **Medium**: Minimalist sculpture, large-scale weathering steel.
- **User's Critique**: User finds his massive steel walls intimidate rather than invite.
- **Physical Effect**: Describes the work as creating "physical discomfort without emotional payoff" and feeling "trapped by the material" rather than transformed by it.

- **Movement Critique**: Specifically criticized for "imprisoning movement" rather than guiding it; makes the user want to "escape." [[entities/auguste_rodin.md]]
- **Architecture Critique**: User describes the work as "architecture that forgot it should serve human experience," highlighting a lack of human connection.
