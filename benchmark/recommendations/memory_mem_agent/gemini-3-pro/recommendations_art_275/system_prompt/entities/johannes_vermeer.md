# Johannes Vermeer
- **Profession**: Dutch Baroque Period Painter
- **Known for**: Masterful treatment of light, domestic interior scenes.

## Key Works
- **Girl with a Pearl Earring**: [[entities/girl_with_a_pearl_earring.md]]

## User Notes
- **Subtlety**: User values Vermeer's "subtlety" over flashy contemporary art, finding that it "rewards patience" and reveals new layers upon multiple viewings.
- **Monumental Domesticity**: User specifically appreciates how Vermeer transforms domestic scenes into something monumental without losing their essence.
