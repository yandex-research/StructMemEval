# Mark Rothko
- **Artistic Style**: Abstract Expressionist, known for Color Field painting.
- **Color Fields**: Described by the user not as rectangles but as "emotional weather systems."
- **Viewer Experience**: The user finds standing before them akin to meditation, feeling the painting "breathe with you." [[entities/rothko_chapel.md]]
- **Soft Edges**: User explicitly values the "soft edges" for inviting quiet contemplation, contrasting this with the visual "assault" of digital screens.
- **Participatory Nature**: Describes the viewing experience as "meeting the work halfway."
