# Rodin Exhibition
- sentiment: Overwhelming
- observation: Feels the "unfinished" rough textures make the human form seem caught mid-breath.
- metaphor: Describes the effect as "stone is learning to be flesh".
- **The Burghers of Calais**: Evoked a sense of weight that was both physical and moral.
- **The Thinker**: Circled three times; noted how each angle revealed a new layer of contemplation in the posture.
- **Comparison**: Contrasts Rodin's work with "smooth marble gods"; finds Rodin's figures more human because they show the "struggle of becoming".
- **Tool Marks**: Values seeing where tools shaped the stone, viewing these "imperfections" as what makes the sculpture breathe—unlike the flawlessness of modern digital renders.
