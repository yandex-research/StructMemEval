# Heat
- genre: Action
- key_scene: Downtown shootout (noted for using real blanks and realistic sound)

- longevity: Believes the film holds up after 25 years because it focused on character and practical filmmaking rather than chasing visual trends.
- rewatch_habit: Rewatches every few months.
- pacing_opinion: Finds that even the slow scenes maintain high tension.
