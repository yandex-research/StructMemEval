# Jackson Pollock
- period: Abstract Expressionism
- notable_works: Number 1A, Autumn Rhythm
- technique: Drip painting, action painting
- materials: Enamel paint, canvas
- user_sentiment: Mixed (Values early work like Number 1A, critical of later repetition)
- user_opinion: Values the "compositional intelligence" hidden in the chaos; dislikes when it feels like "random splatters" without context/biography.

- specific_feedback: Number 1A feels deliberate; later works feel like diminishing returns.

- specific_contrast: Early works feel like "controlled chaos"; later works feel like "chaos pretending to be controlled".- emotional_impact: Confusing, intellectually demanding ("wonder what I'm supposed to feel")
