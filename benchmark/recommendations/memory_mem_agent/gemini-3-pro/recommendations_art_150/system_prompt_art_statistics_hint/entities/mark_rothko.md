# Mark Rothko
- period: Abstract Expressionism
- notable_works: Rothko Chapel, Seagram Murals
- technique: Color field painting, layering thin washes of paint
- materials: Oil on canvas (often large scale)
- user_sentiment: Positive
- themes: Tragedy, ecstasy, doom, spiritual transcendence
- philosophy: silence as the most powerful form of communication
- user_perception: Creates "emotional weather systems" rather than static shapes
- viewing_experience: Meditative; feels like the painting "breathes with you"
- digital_contrast: soft edges vs screening assault
- viewing_context: Values the Chapel setting specifically for enforcing a slow, non-rushed pace unlike museum galleries
- emotional_impact: Immediate, visceral feeling
