# Yayoi Kusama

## User Critique
- **Mirror Rooms**: Acknowledges they create "visceral joy" as an artistic experience.
- **Cultural Critique**: Feels the "Instagram fame" of the work ruins the profound experience, turning it into a mere "selfie backdrop."
- **Logistics**: Notes that the art itself gets "lost" amidst queue logistics and photo opportunities, prioritizing documentation over presence.
- **Viewing Constraint**: Describes the standard 45-second time limit as "experiencing a symphony through a keyhole," wishing instead for hours of solitary contemplation.
