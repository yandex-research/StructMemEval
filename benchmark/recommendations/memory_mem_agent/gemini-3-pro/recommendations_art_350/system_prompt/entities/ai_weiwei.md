# Ai Weiwei
- **Installation**: Exhibited at **Tate Modern**. [[entities/tate_modern.md]]
- **Critique (Sunflower Seeds)**: Acknowledges the political point but found the instruction to walk on the porcelain seeds "gimmicky."
- **Aesthetic Judgment**: Believes the work relies too heavily on instructions, violating the principle that great art shouldn't need "footnotes." 
- **Core Critique**: Explicitly respects the activism but finds the art itself "secondary to the message," describing it as "propaganda with better materials."
