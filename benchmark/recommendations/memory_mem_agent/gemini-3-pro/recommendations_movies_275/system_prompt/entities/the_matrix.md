# The Matrix
- genre: Action / Sci-Fi
- star: [[entities/keanu_reeves.md]]

## User Opinions
- **Impact**: Changed action filmmaking.
- **Critique of copycats**: Most films just copied bullet time without understanding why it worked.
- **Story Integration**: Appreciates that the philosophy and world-building gave the action meaning, noting that every fight advanced the story rather than just being spectacle.
- **Practical Effects**: Appreciates that the subway fight with Agent Smith was real wire work with minimal CGI.
