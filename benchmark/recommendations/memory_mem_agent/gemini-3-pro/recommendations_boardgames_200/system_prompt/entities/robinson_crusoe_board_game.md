# Robinson Crusoe: Adventures on the Cursed Island
- type: Board Game
- genre: Cooperative, Survival
- notes: Known for a complex rulebook that can be intimidating to new players.
- user_experience: The rules complexity led to severe "quarterbacking," where the one knowledgeable player dictated moves for everyone else. Specifically, complexity didn't mitigate the problem but **amplified the alpha player's dominance**, as they were the only ones capable of calculating optimal actions. Observed that the other players "**just nodded and executed instructions**," proving the total lack of agency for the group. While the **theme was interesting**, the game ultimately failed as a cooperative experience due to these issues.
