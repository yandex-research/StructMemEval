# The Crew (Board Game)
- Game Type: Cooperative Trick-taking
- User Experience: Found it "refreshing" as a cooperative experience, standing out against usual dislikes in the genre. Described playing it as **"solving a puzzle together rather than executing a single player's plan"**, highlighting the shared agency.
- **Key Success Factor**: Hidden information enables **genuine collaboration** because no one can see all the cards. This eliminates the 'alpha gamer' problem, requiring every player to contribute meaningfully.
- **Specific Praise**: Forces players to discuss **probabilities and timing** rather than letting one person calculate optimal moves.
