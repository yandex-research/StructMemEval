## Faction Observations
- **Gameplay Contrast**: Explicitly noted the massive difference in feel between playing Vagabond versus Marquise de Cat.

## Player Count Dynamics
- **3 Players**: Described as "tense and strategic"; optimal experience.
- **5-6 Players**: Becomes "chaotic"; significant downtime ("spend half the game waiting").
- **Transformation**: Game changes character completely based on count; prefers lower counts for strategy.

- **Digital Version**: Considering purchase for practice; aims to improve skills efficiently.
