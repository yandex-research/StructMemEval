# Spirit Island
- type: Board Game
- genre: Cooperative, Strategy
- user_experience: Positive; marked as a "good cooperative experience" by the user.
- noteworthy_contrast: Successfully provided a good experience despite user's general dislike of cooperative games (due to quarterbacking issues in Pandemic, etc.).
- **Specific reasons for liking**: Asymmetric powers and separate boards prevent anyone from controlling everything (solving the "alpha gamer" problem); "shared victory feels amazing when it works".
- **Dynamic**: Required "discussing strategy rather than one person dictating moves," directly addressing the user's primary complaint about other cooperative games. Note: "Spirit's abilities were completely different," forcing coordination rather than single-player optimization.
- **Adversary System**: Creates "tension without desperation" when properly calibrated; explicitly valued for providing manageable challenge without feeling hopeless.
