# Mark Rothko
- Artistic Style: Abstract Expressionism, Color Field painting
- User Perception: Color fields are "emotional weather systems," not just rectangles.
- User Experience: Viewing his work feels like meditation; the painting "breathes with you."
- User Perception: Contrasts Rothko's "soft edges" (inviting quiet contemplation/meeting the work halfway) with digital screens (which "assault your eyes").
