# Jackson Pollock
- Era: Abstract Expressionism
- Style: Drip painting, action painting
- User Perception: Undeniable energy, but biography is key to understanding the work. Values the "visible compositional intelligence" beneath the chaos.
- Critical View: Sees later works as diminishing returns where technique overshadows meaning; prefers the deliberateness of earlier work like *Number 1A*. [[entities/number_1a.md]]
