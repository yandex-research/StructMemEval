# Scythe
- **Description**: 4x strategy board game set in an alternate-history 1920s Europe.
- **Mechanics**: Engine building, area control, asymmetric factions.
- **User Experience**: First play went surprisingly well; user felt the resource gathering mechanics successfully captured the feeling of building an industrial empire.
- **Mechanics Feedback**: Liked the "encounter cards" for adding narrative flavor without breaking the gameplay flow.
- **Components**: Loves the resin resource bits; high-quality components enhance the satisfaction of gameplay.
