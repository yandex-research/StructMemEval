# Solo Gaming

## Preferences
- **Disliked Mechanics**: 'Beat your own score' modes (e.g., Terraforming Mars) feel static compared to dynamic AI opponents.
- **Bot Behavior**: Values unpredictability; the bot should feel like a dynamic opponent rather than a predictable flowchart.
- **Puzzle Nature**: Views solo mode as a puzzle that cannot be fully "solved" or memorized.
- **Challenge**: Enjoys being kept on their toes by the AI's moves.
