# Cooperative Dynamics
- **Core Philosophy**: Cooperative games should enforce agency for all players.
- **Problem (Quarterbacking)**: When one player can process the game state better than others, they effectively play solo while others execute instructions.
- **Vulnerability of Asymmetry**: Hidden or asymmetric roles (like in Mysterium) do not inherently solve quarterbacking if one player can still dominate the interpretation or discussion phase, reducing others to passive spectators.
- **Hierarchy vs Collaboration**: Believes that partial asymmetry (e.g., slightly different powers) without full *role differentiation* merely creates a hierarchy where the most experienced player directs others, rather than fostering true collaboration.
- **Solution (Spirit Island)**: Information asymmetry (distinct powers) and complexity distribution force players to focus on their own domains while negotiating boundaries/support with others.
- **Key Preference**: Coordination (negotiating how to solve a problem together) > Optimization (one person solving the puzzle for everyone).
