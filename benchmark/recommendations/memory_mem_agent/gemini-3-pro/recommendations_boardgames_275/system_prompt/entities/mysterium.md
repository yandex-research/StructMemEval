# Mysterium
- type: Board game
- mechanics: Asymmetric communication, ghost-medium dynamic
- notes: User found the premise interesting due to the dynamic between the ghost and mediums.
- critique: Hidden roles and asymmetry didn't prevent quarterbacking; an alpha "medium" can still dominate decision-making by interpreting all visions for the group, leaving the "ghost" (and other players) passive.
- role_imbalance: Felt the medium held all interpretive power while the ghost was relegated to execution-only tasks.
