# Pandemic
- type: Board game
- user_opinion: Negative
- feedback: Disliked due to "quarterbacking" (alpha gamer problem). Described as a "spreadsheet exercise" where one player calculates while others just execute instructions with "zero meaningful decisions". The disease cubes felt like mere tokens to move rather than actual threats, breaking thematic immersion.
- mechanism_critique: Cooperative nature allows one optimal calculator to dominate the group's agency.
- thematic_critique: Loss of immersion; game mechanics stripped away the tension of the theme.
- specific_experience: Played as the Medic and spent three turns just moving where told, reinforcing the feeling of having no agency.
