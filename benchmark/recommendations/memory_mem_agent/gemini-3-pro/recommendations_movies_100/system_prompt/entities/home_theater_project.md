# Home Theater Project
- status: Planning
- design_philosophy: Simplicity (based on user preferences)
- components_needed: Sound system (Priority 1), Projector (Later/Tentative)
- project_priorities: Audio quality > Visual quality

## System Benchmarks
- **Audio/Impact Test**: The glass-breaking scene in Die Hard must be visceral enough to cause a flinch reaction.
- **Bass Requirement**: Explosions must be physically felt in the chest, prioritizing tactile bass response over visual spectacle.
