# Gaia Project
- genre: Heavy Euro / 4X-adjacent
- theme: Sci-Fi Space Colonization
- mechanics: Area Control, Engine Building, Variable Player Powers
- complexity: Very High
- duration: 60-150 mins (typically 2-3 hours)
- **Relation to Twilight Imperium**: Often compared as the "Euro game alternative" to TI's "American style" drama. Much shorter, no dice, perfect information.
- **Key Features**: 
  - 14 Asymmetric Factions
  - Modular Board (Variable Setup)
  - Zero Randomness / Perfect Information

- **User Plan**: Intended for next "heavy session" instead of Twilight Imperium.
