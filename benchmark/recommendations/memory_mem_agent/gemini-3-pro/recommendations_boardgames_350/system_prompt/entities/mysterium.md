# Mysterium
- Type: Cooperative Board Game
- Mechanics: Asymmetric roles (Ghost vs. Mediums), Visual interpretation, Limited communication
- Theme: Supernatural/Mystery
- **User Critique**: Found that **hidden roles failed to prevent quarterbacking**. The game suffered from a severe imbalance where the "medium role" held all the **interpretive power**, while "ghosts" were relegated to **execution-only tasks**, leaving them passive and disengaged.
