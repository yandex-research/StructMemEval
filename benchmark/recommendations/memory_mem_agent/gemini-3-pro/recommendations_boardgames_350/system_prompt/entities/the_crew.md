# The Crew
- **Type**: Cooperative Card Game / Trick-Taking
- **Status**: Played and enjoyed.
- **Sentiment**: Positive
- **User Perspective**: Described as a "refreshing" cooperative experience where hidden information forces **genuine collaboration**.
- **Key Mechanic**: **Distributed Information** (hidden hands). Since no single player can see the entire game state (all cards), optimal play cannot be calculated by one person. This forces every player to contribute meaningfully, effectively solving the "quarterbacking" problem found in games with open information (like Pandemic).
- **Communication**: Strict limits on communication prevent alpha gaming while maintaining tension.
