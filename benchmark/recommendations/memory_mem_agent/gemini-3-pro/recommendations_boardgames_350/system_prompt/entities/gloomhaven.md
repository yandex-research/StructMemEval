# Gloomhaven
- **Genre**: Cooperative Strategy / Dungeon Crawler
- **Complexity**: High (Heavy Euro elements)
- **Key Mechanics**:
    - **Hand Management**: Card-based combat with top/bottom actions.
    - **Hidden Information**: Players select initiative secretly to prevent "quarterbacking".
    - **Legacy Elements**: Permanent world changes, character retirement/progression.
- **Setup**: Notorious for long setup/teardown times without organizers.
- **Duration**: 60-120 minutes per scenario (campaign can take 100+ hours).
- **Related**: [[entities/gloomhaven_jaws_of_the_lion.md]] (Standalone prequel often used as a tutorial).

## User Perspective
- **Intimidation**: The sheer length of the campaign (100+ hours) is a major barrier to entry.
