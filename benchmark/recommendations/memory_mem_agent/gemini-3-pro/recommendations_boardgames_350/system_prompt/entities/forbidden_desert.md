# Forbidden Desert
- type: Cooperative Board Game
- relationship: Sequel to [[entities/forbidden_island.md]]
- mechanics: Grid movement, tile flipping, water management
- design_goal: Intended to address criticisms of simplicity and "quarterbacking" in the original game.
- **Critique**: Failed to fix the "quarterbacking" issue. The same player who dominated Forbidden Island took control here too.
- **Specific Flaw**: Simple mechanics combined with **open information** created a "single-player puzzle with bystanders".
- **Sand Mechanic**: Rather than creating unpredictable chaos, the **sand movement** just became another variable for the **alpha player** to optimize, failing to disrupt the quarterbacking dynamic.
