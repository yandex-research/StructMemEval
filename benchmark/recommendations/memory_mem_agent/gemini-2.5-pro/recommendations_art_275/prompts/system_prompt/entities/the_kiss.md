# The Kiss
- artist: [[entities/gustav_klimt.md]]
- year: 1907-1908
- period: Vienna Secession
- medium: Oil and gold leaf on canvas

## Description
An iconic painting from the Art Nouveau movement, depicting a couple embracing. It is a masterpiece of the artist's "Golden Period".

## User Interpretation
- The gold patterns are not just decoration, but function as "emotional scaffolding" that turns intimacy into architecture, holding the two bodies together.
