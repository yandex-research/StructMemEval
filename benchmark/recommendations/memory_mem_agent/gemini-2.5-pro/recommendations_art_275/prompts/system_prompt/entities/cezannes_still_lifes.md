# Cézanne's Still Lifes
- artist: [[entities/paul_cezanne.md]]
- genre: Still Life
- period: Post-Impressionism

## Key Characteristics
- Exploration of form, color, and composition.
- Multiple viewpoints within a single painting.
- Geometric underpinnings of objects.

## User's Philosophical Insights
- "Cézanne's apples aren't just fruit—they're geological forms testing gravity. His tilted tables don't break perspective; they rebuild it from human doubt."
