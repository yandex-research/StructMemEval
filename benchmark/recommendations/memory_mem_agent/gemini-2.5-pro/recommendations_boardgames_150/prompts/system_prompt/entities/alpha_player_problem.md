# Alpha Player Problem
- **AKA**: Quarterbacking
- **Definition**: A phenomenon in cooperative board games where one player (the "alpha player" or "quarterback") dictates the strategy for the entire group, effectively making decisions for other players.
- **User's Stance**: Strongly dislikes this dynamic. The user believes it removes meaningful decision-making for most players, turning the experience into a simple execution of instructions rather than a collaborative game.

## User's Examples
- On 2024-07-24, the user described a game experience that exemplified this problem: "Our group finished in 20 minutes with zero discussion after the first turn."
