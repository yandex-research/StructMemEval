# The Crew (Game)
- type: Cooperative Card Game
- description: A cooperative trick-taking card game where players must work together to complete specific tasks.

## Gameplay Mechanics
- **Hidden Information**: A core mechanic is that players cannot see all the cards. This restriction is crucial for gameplay.
- **Forced Collaboration**: The hidden information forces genuine collaboration, as no single player has all the necessary information to succeed alone. Everyone must contribute meaningfully based on their limited knowledge.
