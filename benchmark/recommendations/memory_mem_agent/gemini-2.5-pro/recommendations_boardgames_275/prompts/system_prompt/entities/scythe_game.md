# Scythe
- Type: Board Game
- Designer: Jamey Stegmaier
- Core Gameplay: A hybrid Eurogame with elements of engine-building, exploration, and combat set in an alternate-history 1920s period. It's known for its elegant design, minimal downtime, and focus on strategic efficiency over direct conflict. This aligns with the user's preference for meaningful strategy over "multiplayer solitaire."

## Expansions
- **Invaders from Afar**: Adds two new factions (Albion and Togawa), increasing the player count to 7. This expansion is considered essential for adding variety and replayability without changing the core rules. It strongly maintains the original game's balance.
- **The Wind Gambit**: Introduces two modular additions: Airships and Resolutions. Airships are a new unit type, and Resolutions provide alternate end-game triggers. These modules can be mixed and matched, allowing groups to tailor the experience. It can slightly alter the strategic balance depending on the modules used.
- **The Rise of Fenris**: A campaign expansion that adds an 8-game story, along with 11 different modules that can be used in non-campaign games. It significantly increases content but is best experienced after becoming familiar with the base game.
