# Adversary System
- **Core Principle**: An adversary system (like an AI opponent in a cooperative game or a challenging environmental mechanic) should create tension and challenge players without making the situation feel hopeless or desperate.
- **Calibration**: Proper calibration is key. The difficulty should scale in a way that keeps the players engaged and feeling like they have a chance to win, even when behind. It avoids creating a "death spiral" where a small setback leads to an inevitable loss.
