# Forbidden Desert
- type: board_game
- genre: cooperative

## Notes
- According to the user, this game was intended to be a successor to "Forbidden Island" and fix some of its issues.

## Critique
- suffers from the "quarterbacking" problem (also known as the dominant player problem) for the same reason as its predecessor. [[entities/dominant_player.md]]
- The simple mechanics combined with open information can make it feel like a single-player puzzle rather than a cooperative experience for all.
- The user noted that the sand movement mechanic, a core feature, ironically just becomes another variable for a dominant "alpha player" to optimize, reinforcing the quarterbacking issue.
