# Mysterium
- genre: Cooperative deduction
- mechanics:
  - Asymmetric roles (ghost and mediums)
  - Hand management
  - Voting
- user_opinion: While the ghost-medium dynamic is an interesting premise, the user notes that the hidden roles fail to prevent quarterbacking. The medium player often dominates decision-making by interpreting all visions. The user specifically mentioned that "The ghosts just waited for instructions most of the game," highlighting a lack of agency for that role.
