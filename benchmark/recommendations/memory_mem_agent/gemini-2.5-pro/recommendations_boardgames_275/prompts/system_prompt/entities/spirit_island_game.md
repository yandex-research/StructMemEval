# Spirit Island
- type: Board Game
- category: Cooperative Strategy

## Key Mechanics
- Asymmetric Powers: Each player controls a unique spirit with different abilities.
- Separate Player Boards: Each player manages their own section of the island, which prevents a single player from dictating all actions (anti-quarterbacking).
- Shared Victory/Loss: All players win or lose together.
