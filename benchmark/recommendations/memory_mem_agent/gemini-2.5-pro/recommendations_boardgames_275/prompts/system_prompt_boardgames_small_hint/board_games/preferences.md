# Board Game Preferences

## General Preferences
- **Replayability**: The user dislikes abstract games that become predictable after a few plays once optimal strategies are learned.
- **Quarterbacking/Alpha Player Problem**: The user dislikes cooperative games where one player can easily direct everyone else's actions, reducing other players' agency. This is especially true for games with simpler mechanics.
  - **Recent Experience (2024-07-26)**: Noted a game session that finished in 25 minutes where "one player did all the thinking," which is a clear example of this issue.
- **Narrative Elements**: The user appreciates when games include elements like "encounter cards" that add narrative moments without disrupting the game's flow.
- **Player Count & Downtime**: The user dislikes games with long waiting periods between turns, which they find to be a problem in games with higher player counts (e.g., 6 players).

## Game-Specific Notes

### Pandemic
- **Sentiment**: Negative
- **Reason**: User feels the game can become a "spreadsheet exercise" dominated by an alpha player, leaving other players with no meaningful decisions. They described it as one player calculating optimal moves while others just execute instructions.

### Just One
- **Sentiment**: Positive
- **Reason**: The user notes that the game works well with players of mixed experience levels. [[entities/just_one.md]]
