# Strategic Depth vs. Unnecessary Complexity

This document outlines the key differences between valuable strategic depth and unnecessary complexity in board games.

## Core Heuristic
**"Does this rule/mechanic create more meaningful decisions than the cognitive load it adds?"**
- **If YES:** It likely adds strategic depth.
- **If NO:** It's likely unnecessary complexity.

---

## Strategic Depth
Strategic depth emerges from a small set of rules that interact in complex and interesting ways. It gives players a wide range of meaningful choices and long-term viability.

### Signs of Strategic Depth:
- **High Skill Ceiling:** The game is easy to learn but difficult to master. Players continually discover new strategies.
- **Meaningful Decisions:** Players face genuine dilemmas where the best choice is not obvious and depends on context (game state, opponent's actions).
- **Interacting Systems:** Simple mechanics, when combined, create emergent complexity and varied pathways to victory. (e.g., how movement, combat, and resource collection work together in *Scythe*).
- **High Replayability:** The game feels different each time you play because the core systems allow for a wide variety of situations and strategies to unfold.
- **"Just One More Game" Feeling:** It encourages players to try again with a new approach.

### Example:
- In **Go**, the rules are incredibly simple: place a stone, and surround territory/stones. However, the resulting strategic and tactical possibilities are nearly infinite. This is pure strategic depth.

---

## Unnecessary Complexity
Unnecessary complexity consists of rules that add cognitive load without expanding the decision-space in a meaningful way. It's often "chrome" or fiddly rules that bog down the game.

### Signs of Unnecessary Complexity:
- **Rule Exceptions & Edge Cases:** The game has a core loop, but there are dozens of exceptions and "if-then" situations to remember.
- **Fiddliness:** Constant, minor adjustments to the board, tokens, or stats that don't correspond to a major strategic choice.
- **Low-Impact Decisions:** The game presents many choices, but most of them have a negligible impact on the outcome.
- **"Rules Overhead":** Players spend more time consulting the rulebook or managing game state than making strategic decisions.
- **Illusion of Choice:** It seems like there are many options, but there is always a single, mathematically "correct" or obvious choice, making the decision meaningless.

### Example:
- A wargame that requires a player to calculate five different modifiers (terrain, weather, morale, supply line, leader's mood) for a single combat roll, where the final result only shifts the odds by 5%. The cognitive effort far outweighs the strategic impact.
