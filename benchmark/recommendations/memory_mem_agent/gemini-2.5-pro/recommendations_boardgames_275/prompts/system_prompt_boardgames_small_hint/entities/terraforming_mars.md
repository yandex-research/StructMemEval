# Terraforming Mars
- type: board_game

## User Opinions
- feels_like: multiplayer solitaire
- player_interaction: low
- engagement_level: High enough to be played in marathon sessions.
- downtime: Can be an issue during other players' long turns.

## Optimal Player Count
- **General Consensus**: The game is often considered best with 3 players.
- **3 Players**: Strikes a good balance between game length and board interaction. The game state changes enough between turns to be interesting, but downtime is more manageable.
- **4 Players**: Can be a great experience, but significantly increases the game length and potential for downtime between turns, which you have noted as a concern. The board also becomes more crowded, accelerating the end of the game.

## Session Preferences
- **2024-05-21**: User suggested trying the next game with 4 players, believing it might reduce waiting time between rounds.
