# Flash Point: Fire Rescue
- genre: Cooperative
- player_count: 2-6
- theme: Firefighting

## User Notes
- Played with new players, suggesting it's potentially a good introductory or gateway game.
- The game became tedious because the most experienced player directed everyone's actions turn-by-turn. This is a classic example of the "alpha player" or "quarterbacking" problem, which eliminated meaningful choice for other players.
