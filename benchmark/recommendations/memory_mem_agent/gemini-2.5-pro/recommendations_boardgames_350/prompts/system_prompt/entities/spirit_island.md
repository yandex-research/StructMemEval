# Spirit Island
- type: Board Game
- category: Strategy, Cooperative
- player_count: 1-4
- description: A complex cooperative game about spirits defending their island from invading colonists. Known for its high strategic depth and replayability. The user enjoys it for solo sessions.

## Core Mechanics
- **Asymmetric Powers**: Each spirit has unique abilities, encouraging different strategies.
- **Separate Player Boards**: Players manage their own section of the island, which prevents a single player from dominating decisions (i.e., avoids "quarterbacking").
- **Shared Victory**: Players win or lose together, making cooperation essential and rewarding.
