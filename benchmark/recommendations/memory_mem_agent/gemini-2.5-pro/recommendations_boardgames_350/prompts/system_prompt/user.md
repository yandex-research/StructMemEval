## Game Dynamics Concepts
- **Quarterbacking**: A gameplay issue where one dominant player, often an [[entities/experienced_player.md]], makes decisions for the entire group, reducing other players to spectators. The user dislikes this phenomenon, as noted in experiences with [[entities/pandemic.md]], [[entities/forbidden_island.md]], and notes that complex games like [[entities/robinson_crusoe.md]] can paradoxically worsen the issue.
- **Player Autonomy**: A desirable game state where "Each player has unique powers and separate boards. No one can control everything." This prevents quarterbacking and ensures meaningful individual agency.
