# Terraforming Mars
- **Classification**: A strategy game. [[entities/strategy_games.md]]
- type: Board Game
- genre: Strategy, Economic Engine Building
- description: A board game where players act as corporations to terraform the planet Mars by raising the temperature, creating oceans, and increasing the oxygen level.

## User Opinion
- Feels like "multiplayer solitaire", suggesting a low level of direct player interaction.
- The user notes that the game can struggle with downtime during other players' long turns.

## Gameplay Preferences
