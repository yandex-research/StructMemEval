# Mysterium
- **Type**: Cooperative, Deduction
- **Key Mechanic**: Asymmetric roles (Ghost vs. Mediums)
- **Communication**: Ghost communicates with vision cards.

## User Critique
- The hidden roles feature does not effectively prevent quarterbacking.
- The medium player often dominates the decision-making process by interpreting all the vision cards.
- This can result in the ghost players becoming passive participants rather than active collaborators.
