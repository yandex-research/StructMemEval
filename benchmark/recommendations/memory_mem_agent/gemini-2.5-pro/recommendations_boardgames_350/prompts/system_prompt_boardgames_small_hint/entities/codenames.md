# Codenames
- genre: Party game, Word association
- player_count: 2-8+ (best with 4+)
- type: Team-based, Competitive

## Description
A word association game where two teams compete to identify their team's agents from a grid of words. A spymaster gives one-word clues to their teammates to help them guess the correct words.

## User Opinions
- **Stale Gameplay**: The user's regular gaming group finds the game is becoming stale.
- **Memorizable Strategy**: The user feels that optimal strategies and word associations can be memorized after a few plays, reducing the game's long-term replayability and strategic depth.
