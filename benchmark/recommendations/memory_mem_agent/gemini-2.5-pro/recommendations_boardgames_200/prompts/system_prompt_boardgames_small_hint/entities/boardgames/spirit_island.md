# Spirit Island
- type: Cooperative Board Game
- complexity: High
- description: A complex and strategic cooperative game where players act as spirits of the land, defending it from invading colonists.

## User Experience
- **2024-05-23**: The user reported having a "good cooperative experience" with this game. This is notable as it avoids the "alpha player problem" that the user dislikes in other cooperative games like [[entities/pandemic.md]].
- **2024-05-24**: User described it as the "perfect cooperative experience with asymmetric powers and separate boards so no one can control everything—shared victory feels amazing when it works." This highlights a preference for distributed agency and unique player roles.
