# Flash Point: Fire Rescue
- genre: Cooperative
- description: A cooperative game where players work together as firefighters to rescue victims from a burning building.

## User Feedback
- **Experience**: The game became tedious.
- **Reason**: The most experienced player directed everyone's actions turn by turn, which eliminated meaningful choice for other players. This is an example of the "alpha-player problem" the user dislikes.
- **Player Connection**: The user confirmed that the player who took control during this game was the same one known for dominating [[entities/forbidden_island.md]].
