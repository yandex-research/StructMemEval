# Board Game Preferences

## General Preferences
- Dislikes cooperative games where one experienced player can direct everyone's actions (alpha-gaming/quarterbacking).
- Enjoys mechanics that force creative thinking, such as the restriction against duplicate clues in party games.

## Specific Game Notes

### Flash Point
- **Experience**: Became tedious.
- **Reason**: The most experienced player directed everyone's actions turn by turn, eliminating meaningful choice for other players.

### Robinson Crusoe
- **Opinion**: The game's complexity can worsen the alpha player problem. [[entities/boardgames/robinson_crusoe.md]]

### Twilight Imperium
- **Opinion**: Finds the rulebook intimidating. [[entities/boardgames/twilight_imperium.md]]
