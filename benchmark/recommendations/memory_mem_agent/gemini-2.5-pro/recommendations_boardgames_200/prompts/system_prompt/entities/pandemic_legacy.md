# Pandemic Legacy
- type: Board Game
- genre: Cooperative, Legacy
- description: A legacy-style cooperative campaign game based on the mechanics of the original Pandemic. Players work together to stop disease outbreaks while new rules and components are introduced over a campaign of 12-24 games.
