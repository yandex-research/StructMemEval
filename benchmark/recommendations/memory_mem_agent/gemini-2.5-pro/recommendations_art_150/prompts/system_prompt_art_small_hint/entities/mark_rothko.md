# Mark Rothko
- **Movement**: Abstract Expressionism
- **Known for**: Color Field paintings
- **Style**: Characterized by large rectangular blocks of color that create immersive, emotional experiences.

## User Appreciation
- Believes his paintings function as "emotional weather systems" that invite meditation.
- Contrasts Rothko's "soft edges" with the harshness of digital screens, noting they "invite quiet contemplation" where the viewer must "meet the work halfway."
- Believes Rothko understood that silence is a powerful form of artistic communication.
