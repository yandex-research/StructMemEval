# Starry Night
- artist: [[entities/vincent_van_gogh.md]]
- year: 1889
- medium: Oil on canvas

## Description
A famous oil on canvas painting by Dutch Post-Impressionist painter Vincent van Gogh. It depicts the view from the east-facing window of his asylum room at Saint-Rémy-de-Provence, just before sunrise, with the addition of an imaginary village.
