# Mad Max: Fury Road
- director: George Miller
- year: 2015

## Production Facts
- **Filming Style**: Shot with real vehicles and practical effects.
- **Storyboarding**: Director George Miller created 3,500 storyboard panels before filming began.

## Notable Scenes
- **The Sandstorm**: User appreciates that this sequence was filmed with a real sandstorm, believing modern CGI would have looked fake. This reinforces their preference for practical effects.
