# Board Game Preferences

## Likes
- Games where player decisions directly impact what other players can do.
- Games with high-quality, tactile components (e.g., the tiles in Azul).

## Dislikes
- Games with formulaic opening moves.
- Games where the outcome can be predicted early.

## General Views
- Party games are valuable for bringing people together, even if they're not strategically deep, because the social connection can matter more than the gameplay.
