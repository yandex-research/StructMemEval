# Scythe
- genre: Engine-building, Area Control
- player_count: 1-5

## Description
Scythe is a board game set in an alternate-history 1920s period. It's a game of farming and warfare where players explore, expand, exploit, and exterminate.

## Gameplay Mechanics
### Combat System
The combat in Scythe is designed to be deterministic and low-luck, creating tension and deterrence rather than frequent battles. Here's how it works:
- **Threat, not chaos**: Combat is a choice. Players can see potential threats on the board and decide whether to engage.
- **Power Dial**: Each player has a Power Dial, which they secretly set to spend a certain amount of Power (up to 7).
- **Combat Cards**: Players can add one Combat Card per combat unit (Mechs and Leader) involved in the fight. These cards add a strength bonus.
- **Resolution**: The player with the highest total strength (Power Dial + Combat Cards strength) wins. The loser must retreat all their units from the territory to their home base.
- **Consequences**: Winning combat helps players place stars (victory points), but it's costly. Spending Power and Combat Cards depletes resources that are hard to get back. This makes players very selective about when to fight.
