# Codenames
- genre: Party Game, Word Association
- player_count: 2-8+

## Key Characteristics
- **Social Interaction**: Excellent for generating conversation, laughter, and team-based fun.
- **Accessibility**: Simple rules make it easy to learn for new players and different groups (e.g., family).
- **Depth**: While not a deep strategy game, it provides a light and engaging mental puzzle.
